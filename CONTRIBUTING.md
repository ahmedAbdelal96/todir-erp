# Contributing to TODIR

Before changing the repository, read root and scoped `AGENTS.md` files plus applicable canonical documentation. Keep changes small, reviewable, and within one approved scope; no unapproved architecture drift and no assumed branching model.

Assess and document relevant tests, documentation, database migrations, indexes/query behavior, performance, security, tenant isolation, observability, frontend/RTL effects, and operational impact. Do not commit secrets, local/generated junk, logs, build output, or debug artifacts. Self-review before requesting review. A change is done only when its applicable implementation, tests, documentation, and exit gates satisfy the approved plan.
