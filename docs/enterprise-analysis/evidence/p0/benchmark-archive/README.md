# P0 Benchmark Archive

This directory is the durable, versioned archive for the final P0 performance evidence. The files were generated by `backend/Tests/Performance/platform-performance-benchmark.ps1` against the labelled disposable PostgreSQL container `todir.perf.disposable=true`; no shared or customer database was used.

## Contents

| Directory | Profile | Evidence boundary |
|---|---|---|
| `diagnostic/` | Five measured requests per result row, concurrency 1 and 4 | Functional, security, query-plan and resource diagnostics; p95/p99 are insufficient at this sample size |
| `load/` | Superseded 40-request controlled load | Retained for traceability only; not the authoritative p99 run |
| `load-100/` | 100 measured requests per result row, concurrency 1, 4 and 8, two API instances, sustained writes | Controlled local baseline with per-request latency samples and measured p50/p95/p99 |
| `repeat/` | Previously verified identical load profile | Repeatability comparison; the historical JSON is aggregate-only and is labelled accordingly |

Each JSON report contains the run identity, source commit, disposable database identity, dataset snapshot, functional/security/write smoke, per-operation aggregate values, `LatencySamplesMs` (one duration per measured request), query plans, PostgreSQL samples, Docker samples, process-resource peaks and explicit limitations. CSV files retain the PostgreSQL, Docker and process-resource observations.

`PreMigrationSql` is null in the archived final runs. The canonical migration and Development Seed were executed without the compatibility workaround.

## Independent verification

From the repository root, the archive can be checked without the benchmark harness:

```powershell
$archive = Resolve-Path docs\enterprise-analysis\evidence\p0\benchmark-archive
$reports = Get-ChildItem $archive -Recurse -Filter '*.json' |
  Where-Object { $_.Name -like 'platform-performance-*.json' }
foreach ($file in $reports) {
  $report = Get-Content $file.FullName -Raw | ConvertFrom-Json
  if ($report.Certification -notlike '*not a production capacity claim') { throw "Unexpected certification: $($file.FullName)" }
  if ($null -ne $report.Environment.PreMigrationSql) { throw "Compatibility SQL was used: $($file.FullName)" }
  foreach ($row in @($report.ReadResults) + @($report.WriteResults)) {
    if ($null -eq $row.LatencySamplesMs) { continue }
    if ($row.Requests -ne @($row.LatencySamplesMs).Count) { throw "Sample count mismatch: $($file.FullName) / $($row.Operation)" }
    if ($row.Errors -ne 0) { throw "Request errors found: $($file.FullName) / $($row.Operation)" }
  }
}
Get-ChildItem $archive -Recurse -File | Get-FileHash -Algorithm SHA256
```

The final acceptance document records the exact run IDs, sample totals, measured ranges, resource limits, dataset-size limitations and the manifest/checksum update for this archive.
