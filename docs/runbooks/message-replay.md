# Message replay

Quarantine the failed message and inspect its error record without exposing payload secrets. Correct the consumer defect, approve a replay with a reason, operator identity, and exact consumer endpoint, then invoke the registered message replay service; it republishes the original outbox row with the stable message ID, resolves only that endpoint's error after publisher confirmation, and writes the replay audit entry. Verify duplicate delivery produces one business effect and retain the original error and replay audit evidence. The staging verification route is ephemeral and token-protected; production operations must use the authenticated support surface or approved operator command, never direct database edits.
