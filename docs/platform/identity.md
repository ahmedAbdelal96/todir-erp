# Identity and sessions

Identity is global; membership is tenant-scoped; Employee belongs to HR and is not part of the Kernel. Browser sessions use secure, HttpOnly, SameSite cookies. Passwords use PBKDF2 with a per-password salt, and session revocation is checked before authorization through the identity security stamp. MFA uses TOTP with encrypted-at-rest secret material and one-time recovery-code digests; enabled identities must provide a valid code at login. The session revocation endpoint invalidates existing cookies by rotating the security stamp. OAuth/OIDC integrations use authorization code with PKCE; access tokens are never stored in browser local storage.
